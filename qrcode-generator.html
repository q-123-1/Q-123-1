🏛️ 广府古城 - 二维码生成器

⚠️ 重要提示：

二维码无法直接指向本地文件。请先将网站部署到网络服务器，或在本地启动HTTP服务器。

📖 使用说明

1. 部署网站到网络服务器（如 GitHub Pages、Vercel、Netlify）
2. 或在本地启动HTTP服务器（在项目目录运行：npx serve dist -p 8080）
3. 在下方输入网址，点击生成二维码

🚀 免费部署选项

  1. GitHub Pages：将 dist 文件夹上传到 GitHub 仓库，开启 Pages 功能
  2. Vercel：访问 vercel.com，导入项目，一键部署
  3. Netlify：访问 netlify.com，拖拽 dist 文件夹即可部署
